Protocol Overview

This service verifies a user's mobile number via Mobile-Originated (MO) SMS:

  1. Client requests token: Generates a 64-character pure hex token where the first 16 characters are the Request ID.
  2. User sends SMS: The user sends an SMS containing the token to the telco gateway shortcode.
  3. Telco notifies webhook: Telco sends the SMS content and sender's number. The service matches against pending requests and updates status to APPROVED.
  4. Client polls status: Client checks verification status using the 16-character Request ID.

API Endpoints

POST /api/v1/tokens/generate

Generates a new 64-character hex reverse OTP token and stores it in token_requests table.

Request Body

{
  "phoneNumber": "+94771234567"
}

Response (201 Created)

{
  "requestId": "40661646BA0DE70E",
  "token": "40661646BA0DE70E3E8DD12992E7D1580D898767669A9583DAB6096B93F0FC92",
  "phoneNumber": "+94771234567",
  "smsContent": "40661646BA0DE70E3E8DD12992E7D1580D898767669A9583DAB6096B93F0FC92",
  "expiresAt": "2026-10-15T09:47:53.912Z"
}
POST /api/v1/webhooks/telco/sms

Called by Telco provider SMS gateways. Stores incoming message into incoming_messages, extracts the 16-character Request ID, matches against pending tokens for the sender's phone, marks as APPROVED, and responds with a standard acknowledgment.

Request Body

{
  "sender": "+94771234567",
  "message": "40661646BA0DE70E3E8DD12992E7D1580D898767669A9583DAB6096B93F0FC92"
}

Accepted aliases for sender: from, senderNumber, msisdn, mobile. Aliases for message: content, text, body, sms.

Response (200 OK)

{
  "status": "RECEIVED",
  "message": "SMS received successfully"
}
GET /api/v1/tokens/{requestId}/status

Retrieves the verification status and mobile number for a given 16-character Request ID.

Response (200 OK)

{
  "requestId": "40661646BA0DE70E",
  "phoneNumber": "+94771234567",
  "status": "APPROVED",
  "createdAt": "2026-10-15T09:42:53.912Z",
  "expiresAt": "2026-10-15T09:47:53.912Z",
  "verifiedAt": "2026-10-15T09:43:04.245Z"
}

Status Values

StatusDescription
PENDINGToken created, waiting for incoming SMS.
APPROVEDSMS matched and verified successfully.
EXPIREDToken TTL elapsed before matching SMS arrived.

Agent Quick Integration via cURL

# 1. Generate Token
curl -X POST http://localhost:8080/api/v1/tokens/generate \
  -H "Content-Type: application/json" \
  -d '{"phoneNumber": "+94771234567"}'

# 2. Check Status
curl http://localhost:8080/api/v1/tokens/{requestId}/status

# 3. Simulate Webhook
curl -X POST http://localhost:8080/api/v1/webhooks/telco/sms \
  -H "Content-Type: application/json" \
  -d '{"sender": "+94771234567", "message": "{token}"}'
